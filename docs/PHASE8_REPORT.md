# Phase 8 — FEC

L’export des dix-huit champs suit l’ordre relu le 2 octobre 2026 dans l’arrêté du 29 juillet 2013 (article A47 A-1). Seules les lignes validées sont lues. Les écritures de centralisation sont exclues. L’export HTTP exige un exercice `CLOSED` et un validateur sans ERROR. Le fichier et son SHA-256 sont reproductibles. Voir [FEC.md](FEC.md).

L’issue #9 reste ouverte : l’application ne décide pas si le contribuable est tenu de remettre un FEC, et le statut fiscal prêt reste refusé.

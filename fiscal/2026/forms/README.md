# Formulaires 2026

Les numéros de cases de `2033.json` reprennent la liasse 2025 pour garder la même structure de calcul. Ils ne sont pas une publication du millésime 2027 : `case_publication` vaut `blocked`. La feuille de déclaration n’affiche pas ces numéros comme cases à recopier.

`2042-c-pro.json` est `case_not_verified`. Le CERFA des revenus 2026 n’est pas publié. Les cases 5NA, 5NY, 5NK, 5NZ et 5GA ne sont pas reconduites.
